# Dragon P22 reference intake

Place supplied photographs here, outside `public/` and the browser asset pipeline. This folder currently contains no verified photographs. Do not import these files into the application until intake review and image-use rights are approved.

Naming: `dragon-p22_<edition>_<face>_<sequence>.<original-extension>`. For example, use the template `dragon-p22_<edition>_front_01.jpg` after the real edition is confirmed; the template is not a photograph or a claimed edition. Face names: `front`, `back`, `left`, `right`, `top`, `bottom`. Additional names: `three-quarter`, `print-closeup`, `seam-closeup`, `finish-closeup`, `measurement-width`, `measurement-depth`, `measurement-height`.

Keep the unedited originals and record source, photographer/rights holder, date, edition, orientation and permission evidence in the intake record. Photograph the same unopened physical package from all sides in diffuse light, sharply focused, square to the face, without cropping its edges. Include overlapping three-quarter views to establish which faces adjoin. Capture high-resolution straight-on art suitable for UV texturing; avoid glare across print and do not reconstruct missing letters or marks.

Measure the external retail package, not an inner item or assortment count. Record width (left-to-right of the identified front), depth (front-to-back), height (bottom-to-top), all in millimetres. Include ruler/tape photographs, measurement date and any measurement uncertainty. No numerical defaults are supplied.

Store permission documents privately if they contain personal details; `imageUseRights.evidenceReference` may point to a controlled document rather than copying it into this repository. Rights must cover modeling/texturing, derivative renders and website display. A publicly visible photograph alone does not establish those rights.
